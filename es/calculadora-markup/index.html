¿Qué es el Markup?

El markup es el porcentaje de incremento aplicado sobre el precio de coste de un producto para llegar al precio de venta. Se usa ampliamente en el comercio minorista, la industria y el mayorista como método rápido de fijación de precios.

La diferencia fundamental entre markup y margen de beneficio está en la base de cálculo:

  • Margen: calcula el beneficio en relación con el precio de venta (base mayor)
  • Markup: calcula el beneficio en relación con el precio de coste (base menor)

Markup Simple

Markup (%) = [(Venta − Coste) ÷ Coste] × 100

Precio de Venta

PV = Coste × (1 + Markup)

Margen equivalente

Margen = Markup ÷ (1 + Markup)
Error clásico: Un markup del 50% no equivale a una margen del 50%. Con un coste de 100 € y un markup del 50%, el precio de venta es de 150 € y la margen real es solo del 33,33% — no del 50%.

¿Qué es el Markup Divisor y por qué usarlo?

El markup divisor es el método más completo para fijar precios. Considera todos los gastos variables y la margen deseada al mismo tiempo, garantizando que el precio de venta cubra todo y aún genere el beneficio planeado.

Divisor = 1 − (Gastos Variables% + Impuestos% + Margen%)
Precio de Venta = Coste ÷ Divisor

¿Por qué el markup simple no es suficiente en los marketplaces?

Imagina un producto con un coste de 50 €. Aplicas un markup del 60% y llegas a 80 € de precio de venta. Parece estupendo. Pero en Mercado Libre:

  • Comisión 13% = 10,40 €
  • Pasarela 3% = 2,40 €
  • Impuesto 6% = 4,80 €
  • Total de tarifas = 17,60 €
  • Coste real = 50 € + 17,60 € = 67,60 €
  • Beneficio real = 80 € − 67,60 € = 12,40 € (15,5% de margen)

Con el markup divisor, defines la margen deseada (por ejemplo, 20%) y el sistema calcula el precio correcto automáticamente: 50 € ÷ (1 − 0,13 − 0,03 − 0,06 − 0,20) = 50 € ÷ 0,58 = 86,21 €.

Cuándo Usar Markup y Cuándo Usar Margen

Usa Markup cuando...

  • Necesites aplicar un multiplicador fijo sobre una gama de productos
  • Tu sector use el markup como estándar de mercado (industria, mayorista)
  • Necesites rapidez al fijar precios de muchos SKU
  • Uses el markup divisor para absorber todas las tarifas de una vez

Usa Margen cuando...

  • Quieras saber exactamente cuánto de la facturación es beneficio
  • Trabajes con objetivos de rentabilidad sobre la facturación
  • Analices la viabilidad del negocio y hagas proyecciones
  • Compares la rentabilidad entre diferentes productos o categorías
